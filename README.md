# MeWeGo Bot

Telegram бот для приёма заявок с сайта MeWeGo Growth.

## Развертывание на Vercel

### 1. Настройка переменных окружения

В настройках проекта Vercel добавьте переменную окружения:
- `BOT_TOKEN` — токен вашего Telegram бота от @BotFather

### 2. Деплой

```bash
vercel deploy
```

## Локальная разработка

### Установка зависимостей
```bash
pip install -r requirements.txt
```

### Настройка локального окружения
Создайте файл `.env`:
```
BOT_TOKEN=your_bot_token_here
PORT=5000
```

### Запуск webhook сервера
```bash
python webhook.py
```

### Запуск бота (отдельно)
```bash
python bot.py
```

## Настройка бота

1. **Создайте бота** через @BotFather в Telegram
2. **Получите токен** и добавьте его в переменные окружения Vercel
3. **Добавьте бота в нужный чат** (личный или групповой)
4. **Напишите боту команду `/start`** в этом чате
5. Бот автоматически сохранит chat_id и будет отправлять туда заявки

## Дополнительные команды бота

- `/start` — Устанавливает текущий чат как администраторский для получения заявок
- `/setchat` — Явно устанавливает текущий чат как администраторский
- `/chatid` — Показывает ваш текущий chat ID

## API Endpoint

- `/webhook/lead` — Приём заявок с формы сайта
- `/webhook/xray` — Приём результатов Business X-Ray
- `/health` — Проверка здоровья сервиса

## Безопасность

- Токен бота хранится в переменных окружения Vercel
- В репозитории токен не коммитится
- Используется только официальный Telegram API
